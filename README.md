# NeuroMaster 赛事统分后台管理系统 · Demo

BrainCo（强脑科技）赛事评分系统的**后台管理端**交互原型。单文件、零依赖、可离线运行。

> 本仓库为**产品原型 Demo**，用于需求评审与交互验证，不含后端服务与真实业务数据。

## 快速开始

用浏览器直接打开 `index.html` 即可 —— 无需服务器、无需联网、无需安装任何依赖。

## 功能模块

| 分组 | 模块 | 说明 |
|---|---|---|
| 运营管理 | **总览** | 赛项状态、队伍 / 签字 / 公示统计 |
| 运营管理 | **赛项与规则** | 赛项、任务、得分、奖项、同分裁决自由配置；配置快照与回滚 |
| 运营管理 | **赛台与赛程** | 赛台数量可配；赛台 × 时段场次编排；就近自动分配 + 手动改派；加时赛场次（场内快照） |
| 运营管理 | **队伍管理** | 新增 / 弃赛（软删除，保留历史成绩）/ 改组，全部留痕 |
| 运营管理 | **WRC 报名导入** | 直读 `.xlsx`（自研解析）；列映射；变更比对（新增 / 更新 / 跳过 / 冲突）；合并式入库 |
| 现场执行 | **裁判打分** | 按评分方式自动渲染控件；用时 / 黄红牌；选手签字；改分申请（需裁判长授权） |
| 现场执行 | **实时榜单** | 两轮取优 → 加权计分 → 加分 → 扣牌 → 排名 → 奖项分配 |
| 现场执行 | **现场大屏** | 分页轮播（每屏 10 条 / 停留 1 分钟）；姓名脱敏；置顶 / 锁定本场 |
| 结果与合规 | **公示与导出** | 公示表（仅排名）与成绩表（含明细）两类产物；CSV 导出 |
| 结果与合规 | **操作审计** | 六类操作全留痕（改配置 / 改分 / 弃赛 / 改组 / 调赛台 / 删队），含旧值 → 新值 + 原因 |

## 技术特点

- **单文件**：HTML + CSS + 原生 JavaScript 全部内联，无构建步骤、无依赖安装
- **离线可用**：数据存 localStorage，断网可正常操作，恢复后可同步
- **零第三方库**：`.xlsx` 解析为自行实现（ZIP central directory + `DecompressionStream('deflate-raw')` + XML 扫描），未引入 SheetJS 等外部依赖
- **界面全中文 / 内部键英文**：界面只出现中文术语（如「数值评分」「加权求和」），内部存储仍用英文键（如 `numeric`、`weighted_sum`），与配置 Schema 完全兼容

## 数据说明

- 仓库内数据均为**模拟演示数据**（虚构的队伍、学校、成绩）
- Demo 数据仅保存在浏览器本地 localStorage，不会上传到任何服务器
- 清除浏览器数据即恢复内置种子数据，也可用界面右上角「重置种子」
