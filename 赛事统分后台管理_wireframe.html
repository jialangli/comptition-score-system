隔离：一场赛事一份数据空间，不是给每张表加 contestId 列，而是整体换存储 key。 好处是所有既有视图（打分 / 榜单 / 大屏 / 工单 / 留底 / 审计）零改动即天然隔离。
归档是真只读：归档行的按钮是 disabled 态而非「点了提示一下」， 写入接口层另有 403 硬拦 —— 只禁用按钮等于没锁。
新建赛事默认勾选全部赛项，勾选后带入完整规则（任务 / 分值 / 判罚事由 / 争议类型）， 赛程表只保留被勾选赛项的分台，避免出现指向不存在赛项的场次。

① 不做跨赛事总分排名。不同赛事的赛制、难度、权重都不同，总分不可比。 硬排一个「总榜」是好看但错误的 —— 所以本表只按「参赛场次 → 最佳名次 → 平均分」排序， 只回答「谁参加过哪几场、各场表现如何」。
② 队名 + 学校 近似归并，跨场严格身份需要 `team_uid`。
③ 各场名次都是「该场当时的官方名次」：已剔除取消资格的队伍、按该场递补规则算，与各场公示一致。
这一页存在的意义是「不排名」。如果哪天有人要求「给我一个跨赛事的总排名」， 正确答案是做不到 —— 而不是做个看起来能用的表。这条约束写在 note 里，避免后续被当成待办做掉。

6 位 + 排除易混字符：裁判在现场要手抄 / 口述，「0 与 O」「1 与 I」混淆是真实事故来源。
激活状态单独一列：发码 ≠ 激活。裁判码首登联网激活后，平板端才有离线登录资格。
